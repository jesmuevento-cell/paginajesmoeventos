# REGRAS DO PROJETO

1. Não alterar funcionalidades existentes sem solicitação.
2. Não alterar o layout global.
3. Não alterar cores ou tipografia sem solicitação.
4. Não alterar o modelo Firestore sem solicitação.
5. Fazer alterações mínimas.
6. Reutilizar componentes existentes.
7. Não duplicar componentes.
8. Não fazer refatoração não solicitada.
9. Não remover funcionalidades existentes.
10. Antes de alterar arquivos críticos, analisar suas dependências.
11. Após cada alteração, informar os arquivos modificados.
12. Se houver risco de quebrar uma funcionalidade existente, parar e explicar o risco.
